# 234. Palindrome Linked List

## 题目描述

Given the `head` of a singly linked list, return `true` if it is a palindrome or `false` otherwise.

**Example 1:**
```
Input: head = [1,2,2,1]
Output: true
```

**Example 2:**
```
Input: head = [1,2]
Output: false
```

**Constraints:**
- The number of nodes in the list is in the range `[0, 10^5]`.
- `0 <= Node.val <= 9`

## 解题思路

判断链表是否为回文结构。提供两种实现方式：递归和迭代。

### 方法一：递归

**核心思想**：
利用递归的后序遍历特性，先递归到链表末尾，然后在回溯过程中从后向前比较节点值。

**算法步骤**：
1. 使用成员变量 `front` 指向链表头部
2. 递归遍历到链表末尾
3. 在回溯过程中，比较当前节点值与 `front` 指向的节点值
4. 如果相等，`front` 向后移动；如果不相等，返回 false
5. 继续回溯，直到所有节点都比较完

**关键点**：
- 递归天然地实现了从后向前的遍历
- 使用成员变量 `front` 跟踪前向指针，避免参数传递
- 空链表和单节点链表都是回文

### 方法二：迭代（快慢指针 + 链表反转）

**核心思想**：
使用快慢指针找到链表中点，反转后半部分链表，然后比较前后两部分。

**算法步骤**：
1. **找中点**：使用快慢指针，快指针每次走两步，慢指针每次走一步，当快指针到达末尾时，慢指针在中点
2. **反转后半部分**：从中点开始反转链表
3. **比较**：同时遍历前半部分和反转后的后半部分，比较节点值
4. **恢复链表**：再次反转后半部分，恢复原链表结构（可选）

**关键点**：
- 快慢指针找中点：快指针到达末尾时，慢指针正好在中点
- 反转链表：使用三指针法（prev, curr, next）
- 只需要比较到后半部分结束即可
- 恢复链表是可选的，题目不要求

**两种方法对比**：
- 递归：代码简洁，空间复杂度 O(n)，可能栈溢出
- 迭代：代码稍复杂，空间复杂度 O(1)，不会栈溢出

## 复杂度分析

### 方法一：递归

- **时间复杂度**：O(n)，其中 n 是链表的长度。需要遍历整个链表。
- **空间复杂度**：O(n)，其中 n 是链表的长度。空间复杂度主要来自递归调用栈。最坏情况下（链表很长）可能导致栈溢出。

### 方法二：迭代

- **时间复杂度**：O(n)，其中 n 是链表的长度。需要遍历链表找到中点、反转链表、比较节点值。
- **空间复杂度**：O(1)，只使用了常数级别的额外空间（几个指针）。
