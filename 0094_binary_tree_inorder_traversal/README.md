# 94. Binary Tree Inorder Traversal

## 题目描述

Given the `root` of a binary tree, return the inorder traversal of its nodes' values.

**Example 1:**
```
Input: root = [1,null,2,3]
Output: [1,3,2]
```

**Example 2:**
```
Input: root = []
Output: []
```

**Example 3:**
```
Input: root = [1]
Output: [1]
```

**Constraints:**
- The number of nodes in the tree is in the range `[0, 100]`.
- `-100 <= Node.val <= 100`

## 解题思路

中序遍历的访问顺序是：左子树 → 根节点 → 右子树。提供两种实现方式：递归和迭代。

### 方法一：递归

**算法步骤：**
1. 如果当前节点为空，直接返回
2. 递归遍历左子树
3. 访问当前节点（将值加入结果）
4. 递归遍历右子树

**关键点：**
- 递归天然地实现了中序遍历的顺序
- 通过引用传递结果向量，避免拷贝
- 基准情况是节点为空

### 方法二：迭代（使用栈）

**算法步骤：**
1. 初始化一个栈和当前指针指向根节点
2. 当当前指针不为空或栈不为空时：
   - **向左走**：一直向左走，将沿途节点压入栈
   - **访问节点**：当走到空节点时，弹出栈顶节点并访问
   - **转向右子树**：将当前指针指向右子树
3. 返回结果

**关键点：**
- 使用栈模拟递归调用栈
- 先一直向左走，将节点压入栈
- 弹出栈顶时，该节点是当前最左边的节点，应该访问
- 访问后转向右子树，重复上述过程

**两种方法对比：**
- 递归：代码简洁，但可能栈溢出（树很深时）
- 迭代：空间可控，避免栈溢出，代码稍复杂

## 复杂度分析

### 方法一：递归

- **时间复杂度**：O(n)，其中 n 是二叉树的节点数。每个节点被访问一次。
- **空间复杂度**：O(h)，其中 h 是二叉树的高度。空间复杂度主要来自递归调用栈。最坏情况下（树退化为链表）为 O(n)，平均情况下为 O(log n)。

### 方法二：迭代

- **时间复杂度**：O(n)，其中 n 是二叉树的节点数。每个节点被访问一次。
- **空间复杂度**：O(h)，其中 h 是二叉树的高度。空间复杂度主要来自栈。最坏情况下（树退化为链表）为 O(n)，平均情况下为 O(log n)。
