# 509. Fibonacci Number

## 题目描述

斐波那契数，通常用 F(n) 表示，形成的序列称为斐波那契数列。该数列由 0 和 1 开始，后面的每一项数字都是前面两项数字的和。也就是：

```
F(0) = 0, F(1) = 1
F(n) = F(n - 1) + F(n - 2), for n > 1.
```

给定 n，计算 F(n)。

### 示例

**示例 1：**
```
输入: n = 2
输出: 1
解释: F(2) = F(1) + F(0) = 1 + 0 = 1.
```

**示例 2：**
```
输入: n = 3
输出: 2
解释: F(3) = F(2) + F(1) = 1 + 1 = 2.
```

**示例 3：**
```
输入: n = 4
输出: 3
解释: F(4) = F(3) + F(2) = 2 + 1 = 3.
```

### 约束条件

- `0 <= n <= 30`

## 解题思路

使用迭代方式（动态规划的空间优化版本）来计算斐波那契数：

1. **基础情况处理**：当 n < 2 时，直接返回 n（F(0) = 0, F(1) = 1）
2. **迭代计算**：使用三个变量分别保存：
   - `prev`：保存 F(n-2)
   - `curr`：保存 F(n-1)
   - `next`：保存 F(n)
3. **逐步更新**：从 i = 2 到 n，每次计算 next = prev + curr，然后更新 prev 和 curr
4. **返回结果**：最终返回 curr

**关键点**：
- 避免递归的重复计算，时间复杂度从指数级降低到线性
- 只保存前两项的值，空间复杂度从 O(n) 降低到 O(1)
- 迭代方式比递归方式更高效，不会出现栈溢出问题

## 复杂度分析

- **时间复杂度**：O(n)，其中n是输入值
  - 需要从2遍历到n，共n-1次迭代
- **空间复杂度**：O(1)
  - 只使用了三个变量（prev, curr, next）
