# 387. First Unique Character in a String

## 题目描述

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 `-1`。

### 示例

**示例 1：**
```
输入: s = "leetcode"
输出: 0
```

**示例 2：**
```
输入: s = "loveleetcode"
输出: 2
```

**示例 3：**
```
输入: s = "aabb"
输出: -1
```

### 约束条件

- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母

## 解题思路

使用计数数组（哈希表的优化版本）来求解：

1. **统计频率**：使用长度为26的数组统计每个小写字母的出现频率
2. **查找第一个唯一字符**：再次遍历字符串，找到第一个频率为1的字符
3. **返回索引**：返回该字符的索引，如果没找到则返回-1

**关键点**：
- 由于题目限定字符串只包含小写字母，可以使用固定大小数组（26个元素）
- 数组索引通过 `ch - 'a'` 计算，实现O(1)时间复杂度的查找
- 需要两次遍历字符串，但总体时间复杂度仍为O(n)

## 复杂度分析

- **时间复杂度**：O(n)，其中n是字符串长度
  - 第一次遍历统计字符频率：O(n)
  - 第二次遍历查找第一个唯一字符：O(n)
- **空间复杂度**：O(1)，使用固定大小数组（26个元素）
