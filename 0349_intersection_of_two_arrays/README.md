# 349. Intersection of Two Arrays

## 题目描述

给定两个整数数组 `nums1` 和 `nums2`，返回一个数组中的交集。结果中的每个元素必须是唯一的，你可以按任意顺序返回结果。

### 示例

**示例 1：**
```
输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]
```

**示例 2：**
```
输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]
```

### 约束条件

- `1 <= nums1.length, nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 1000`

## 解题思路

使用哈希表（unordered_set）来求解数组交集：

1. **去重**：将第一个数组 `nums1` 中的所有元素插入到 `unordered_set` 中，自动去重
2. **查找交集**：遍历第二个数组 `nums2`，对于每个元素，如果它存在于第一个集合中，则将其加入结果集合
3. **返回结果**：将结果集合转换为 vector 返回

**关键点**：
- 使用 `unordered_set` 实现 O(1) 平均时间复杂度的查找
- 结果也使用 `unordered_set` 来保证唯一性
- 只使用一个集合存储 `nums1`，空间复杂度为 O(n)

## 复杂度分析

- **时间复杂度**：O(n + m)，其中 n 和 m 分别是 `nums1` 和 `nums2` 的长度
  - 构建 `nums1` 的集合需要 O(n)
  - 遍历 `nums2` 并查找需要 O(m)
- **空间复杂度**：O(n)，用于存储 `nums1` 的集合和结果集合
