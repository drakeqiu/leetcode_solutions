# 387. First Unique Character in a String

## 题目描述

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 `-1`。

### 示例

**示例 1：**
```
输入: s = "leetcode"
输出: 0
```

**示例 2：**
```
输入: s = "loveleetcode"
输出: 2
```

**示例 3：**
```
输入: s = "aabb"
输出: -1
```

### 约束条件

- `1 <= s.length <= 10^5`
- `s` 只包含小写英文字母
